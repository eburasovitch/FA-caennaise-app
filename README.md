# fa-caen-site

Site statique de FA Caen, publié sur GitHub Pages.

- `src/` : les pages du site
- `DESIGN.md` : la charte graphique que Claude suit
- `CLAUDE.md` : les règles de travail pour Claude
- `.claude/skills/` : skills de design (taste-skill, web-design-guidelines, playwright-cli)
- `.claude/settings.json` : plugin Impeccable et installation automatique de playwright-cli

Mettre à jour les skills : `npx skills update -p`.
